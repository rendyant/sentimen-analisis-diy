# Data Ghifa — OPD DIY

Folder ini berisi data ulasan hasil scraping untuk OPD bagian Ghifa.

## OPD yang Dipantau

| ID | Nama Instansi |
|----|---------------|
| dinkes | Dinas Kesehatan DIY |
| dinsos | Dinas Sosial DIY |
| diskopukm | Dinas Koperasi dan UKM DIY |
| disperindag | Dinas Perindustrian dan Perdagangan DIY |
| dpmptsp | Dinas Penanaman Modal dan PTSP DIY |

## Format CSV

Kolom: `id_ulasan, instansi_id, instansi_nama, sumber, penulis, teks, rating, tanggal, url, scraped_at`

## Sumber Data

- `berita` — Google News RSS
- `maps` — Google Maps Reviews
- `twitter` — Twitter/X
